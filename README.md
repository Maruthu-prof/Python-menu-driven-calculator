# Python-meny-driven-calculator
#  Project Title

Menu-Driven Calculator Using Python



Objectives

Develop a simple calculator using Python.
Understand the concept of menu-driven programming.
Perform basic arithmetic operations.
Practice using loops and conditional statements.
Improve problem-solving and programming skills.
Learn how to handle user input and invalid choices.



# Features

* Addition of two numbers
* Subtraction of two numbers
* Multiplication of two numbers
* Division of two numbers
* Menu repeats until the user chooses to exit
* Handles invalid menu selections
* Prevents division by zero
* Simple and user-friendly console interface

---

# How to Run

### Step 1: Save the Program

Save the Python code as:


calculator.py


### Step 2: Open Terminal or Command Prompt

Navigate to the folder where the file is saved.


cd path/to/project


### Step 3: Run the Program

python calculator.py



### Step 4: Use the Menu

* Enter your choice (1–5).
* Input two numbers.
* View the result.
* Repeat until you select Exit.
